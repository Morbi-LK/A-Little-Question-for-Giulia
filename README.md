# 💗 A Little Question

A small romantic date invitation website.

## Open it locally

Double-click `index.html`.

## Put it on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save.

GitHub will give you a public website URL.

## Customize it

The main text is in `index.html`.

The date range is currently **October 7–11**.

If you want to change colors, animations, fonts, or layout, edit `style.css`.
